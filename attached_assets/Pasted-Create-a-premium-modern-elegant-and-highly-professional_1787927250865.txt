Create a **premium, modern, elegant and highly professional UI/UX design** for a swimming pool website called **“Abbasi Farm Swimming Pool”**, located in Muzaffargarh, Pakistan.

This is a **UI design project only**. Do not build backend, APIs, database, authentication logic or actual payment processing. Focus entirely on creating a polished, production-quality frontend experience and realistic interactive UI states.

## Brand & Visual Direction

The website should feel like a **premium private swimming club / resort**, while still being appropriate for a local Pakistani business.

Design style:

* Premium
* Clean
* Modern
* Elegant
* Trustworthy
* Family-friendly
* Spacious
* Professional

Color direction:

* Deep navy blue
* Aqua / swimming-pool blue
* White
* Very light gray
* Subtle teal accents

Use high-quality outdoor swimming pool imagery, elegant typography, generous whitespace, soft shadows, rounded cards and subtle animations.

Avoid:

* Cheap-looking template designs
* Excessive gradients
* Neon colors
* Overly colorful UI
* Cluttered layouts
* Generic Bootstrap-style appearance

# UI QUALITY REQUIREMENT

The final result should look like a **real premium commercial website**, not an AI-generated template.

Focus on:

* Strong visual hierarchy
* Excellent spacing
* Consistent typography
* Premium imagery
* Elegant cards
* Smooth transitions
* Clear CTAs
* Accessible forms
* Professional empty states
* Loading states
* Error states
* Success states
* Confirmation modals
* Toast notifications

Most importantly, make the **booking journey extremely simple**:

**Date → Time → Visitors → Customer Details → Summary → Confirmation**

The user should always know:

**What they selected → How many spots are available → What they will pay → What happens next.**
