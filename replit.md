# Replit setup

## Run the app

The project uses React, TanStack Start, and Vite.

```sh
npm run dev -- --host 0.0.0.0 --port 5000
```

The Replit `Start application` workflow runs this command and serves the web preview on port 5000. Node.js 22 is selected because the TanStack Start dependencies require Node.js 22.12 or newer.

## Build

```sh
npm run build
```

No external services or additional secrets are required by the current project configuration.
